# Product <!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
static HTML5 / CSS3 / JavaScript (Vanilla, sin frameworks, compatible con GitHub Pages)

## Users
Fans y seguidores del proyecto musical ESH. Acceden mayoritariamente desde dispositivos móviles mediante enlaces en redes sociales (Instagram, TikTok, Spotify, etc.) buscando apoyar al artista y adquirir merchandising oficial de forma ágil, segura y sin fricciones.

## Product Purpose
Servir como la tienda web oficial de merchandising del proyecto musical ESH. Permite exhibir el catálogo oficial con mockups reales, configurar opciones de producto (tallas, variantes) y concretar pedidos de manera directa y transparente.

## Key Workflows
1. **Descubrimiento y catálogo**: Navegación de los productos oficiales con visualización detallada de mockups y fotos de frente/espalda/ángulo.
2. **Configuración de producto**: Selección intuitiva de talla, color/variante y cantidad.
3. **Gestión de carrito**: Carrito de compras interactivo con persistencia local (`localStorage`), control de cantidades y desglose de totales.
4. **Checkout y cierre de pedido**: Formalización del pedido generando un mensaje claro y estructurado para concretar la compra vía WhatsApp o mensaje directo.

## Constraints & Principles
- **Arquitectura estática pura**: HTML5 semántico, CSS3 moderno y JavaScript Vanilla sin dependencias externas, optimizado para alojamiento en GitHub Pages.
- **Enfoque Mobile-First**: Rendimiento de carga instantáneo y UI fluida, pensada primordialmente para navegación táctil y pantallas pequeñas.
- **Persistencia en cliente**: Carrito almacenado en `localStorage` para preservar el estado del usuario ante recargas o navegación.
- **Autonomía y portabilidad**: Sin necesidad de servidor backend ni base de datos para operar el flujo de pedidos.

## Voice & Tone
Cercana, profesional, auténtica y alineada con la identidad artística del proyecto musical ESH.
